Algorithmic Trade-Offs & Architecture
📐 TF-IDF (Microsoft.ML)
Latency: ~0.1-2 ms
Memory: ~4 MB
Strengths: Sub-millisecond speed, 100% token explainability, exact keyword matching.
Weakness: Brittle to spelling errors and vocabulary mismatch (synonyms).
⚡ FastText (Char n-grams)
Latency: ~0.4-3 ms
Memory: ~11 MB
Strengths: Exceptional typo and morphological resilience via subword hashes (lengths 3-5).
Weakness: Bag-of-ngrams loses word order and high-level conceptual context.
🧠 BERT (Transformer INT8)
Latency: ~15-35 ms
Memory: ~35 MB
Strengths: Deep semantic understanding, synonym generalization, MaxSim index matching.
Weakness: Higher CPU latency and memory footprint; requires neural inference.
